# 🛒 Amazon Clone

A responsive front-end clone of the Amazon homepage built using **HTML5** and **CSS3**. This project was created to practice web development fundamentals such as layouts, Flexbox, positioning, and responsive design.

## 🚀 Features

- Amazon-inspired homepage layout
- Responsive navigation bar
- Search bar UI
- Hero banner section
- Product cards and shopping categories
- Footer with multiple sections
- Clean and organized code structure
- Fully built using HTML and CSS (No JavaScript)

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design
